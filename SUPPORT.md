# Помощь покупателям Excel Factory

### Где приобрести программу?

Полная версия Excel Factory 1.4 продаётся через [официальную страницу на Kwork](https://kwork.ru/software/55517082/excel-factory-professionalniy-generator-tablits-excel). В этом репозитории нет установщика или бесплатной копии программы.

### Нужно ли уметь программировать?

Нет. В программе есть библиотека шаблонов, пошаговый мастер и собственный конструктор.

### Работает ли программа без интернета?

Основные функции — да. Для работы ИИ-помощника DeepSeek требуется интернет и самостоятельно подключённый API-ключ.

### Нужен ли Microsoft Excel?

Excel Factory формирует XLSX-файлы. Для просмотра и редактирования сохранённых документов нужен Microsoft Excel или совместимый табличный редактор, например LibreOffice Calc.

### Где находятся готовые таблицы?

По умолчанию в папке `Документы\ShashevPro Excel`. Путь можно изменить в настройках программы.

### Как безопасно проверять и улучшать существующие файлы?

Сохраните копию важных исходных файлов. Проверяйте предложенные действия перед сохранением изменённого результата.

### Куда обращаться по вопросам покупки и получения программы?

Напишите продавцу через переписку по заказу [Kwork](https://kwork.ru/software/55517082/excel-factory-professionalniy-generator-tablits-excel). Сведения о разработчике доступны на [shashevpro.ru](https://www.shashevpro.ru/).
